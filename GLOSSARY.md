# Plain-Language Glossary

## ACH

**Analysis of Competing Hypotheses.** A structured method that compares several possible explanations instead of choosing the first plausible answer.

## Confidence

How strongly the available evidence supports a conclusion. Confidence is separate from severity: an event can be high impact but weakly supported.

## CVE

**Common Vulnerabilities and Exposures.** A public identifier assigned to a disclosed software vulnerability.

## Defanged Indicator

A domain, URL, or IP address rewritten so it is not directly clickable. For example, `example[.]com` instead of `example.com`.

## Diamond Model

An intrusion-analysis framework connecting four core features: adversary, capability, infrastructure, and victim.

## IOC

**Indicator of Compromise.** A technical value such as a malicious hash, domain, IP address, or file name that may help identify suspicious activity. Not every investigative pivot is a confirmed IOC.

## Initial-Access Broker (IAB)

A seller that obtains access to an organisation and sells that access to another criminal operator.

## KEV

**Known Exploited Vulnerabilities.** CISA's catalog of vulnerabilities with evidence of real-world exploitation.

## N-day

An exploit for a vulnerability that has already been publicly disclosed. Defenders may know about the flaw even if systems remain unpatched.

## OSINT

**Open-Source Intelligence.** Information collected and analysed from legally accessible public sources.

## PTR / Reverse DNS

A DNS lookup that maps an IP address back to a hostname. It can identify an infrastructure provider but does not prove ownership or malicious intent.

## RaaS

**Ransomware as a Service.** An operating model in which core developers maintain ransomware and infrastructure while affiliates perform intrusions and share proceeds.

## RDAP

**Registration Data Access Protocol.** A standard service for retrieving domain-registration metadata such as registrar, dates, status, and sometimes registrant information.

## Source Lineage

The path a claim follows from its earliest identifiable source through later articles. Multiple articles repeating one report do not provide independent confirmation.

## TLP:CLEAR

A Traffic Light Protocol marking indicating information may be shared publicly, subject to normal copyright rules.

## TTP

**Tactics, Techniques, and Procedures.** A description of how an adversary operates.

## Typosquat

A domain designed to resemble a legitimate brand through spelling, character, or suffix changes. Similarity alone does not prove malicious use.

## Zero-day

A vulnerability unknown to, or not yet patched by, the affected vendor when exploitation begins. Advertisements often misuse this term, so technical proof and chronology matter.
